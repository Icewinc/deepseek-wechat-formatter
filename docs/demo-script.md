# 演示方案（3–5 分钟）

## 建议环境

- 已运行：`npm run dev`，浏览器打开 `http://localhost:3000/`
- 备用：直接展示 `demo/01-input.png → demo/02-output.png → demo/03-copy-success.png` 三张截图

## 演示流程

### 第 1 步：讲清问题（约 40 秒）

> 品牌公众号每次发文都要手动统一标题、字号、间距、配色；不同小编排出来风格还不一样。这个排版器的思路是：把“品牌版式”锁成一套固定规则，用户只需要粘贴文字。

### 第 2 步：展示输入态（约 40 秒）

- 左侧已载入一篇“DeepSeek-V4-Pro 正式版上线”示例（纯文字）；
- 指出左下角实时识别的结构：标题、副标题、导语、章节、列表、重点、引用；
- 说明右上角字数/阅读时长。

### 第 3 步：一键排版（约 60 秒）

- 点击“一键排版”；
- 指向右侧公众号预览：375px 宽度、深蓝标题、SECTION 编号、品牌蓝重点卡片、引用块、文末 DEEPSEEK 结束区；
- 强调“所有样式都是内联样式，不依赖本站 CSS”。

### 第 4 步：复制与粘贴（约 60 秒）

- 点击“复制到公众号”，展示按钮变为“已复制 ✓”；
- 说明同时写入富文本和纯文本；
- 若演示环境允许：打开公众号编辑器粘贴并展示效果；
- 若环境不允许：明确说明“真实公众号粘贴需要后台权限，本演示已验证复制载荷完整，最后一步请在有权限的环境确认”。

### 第 5 步：收尾（约 40 秒）

- 一句话总结亮点：确定性排版、品牌锁版式、内容不出浏览器、交付完整；
- 主动说出当前缺点（不支持图片/表格、语法依赖规则、未做真实公众号端到端），体现边界意识。

## 讲解话术示例

> “我把标题、正文、重点、引用都做成了可识别的结构。比如 `重点：` 会变成品牌蓝的 KEY POINT 卡片，`##` 或“一、”会变成自动编号的章节。它不猜内容，规则是确定性的，所以同一段文字排一百次结果都一样。”

> “复制不是复制网页截图，而是复制带内联样式的富文本，这样粘贴到公众号编辑器后，样式还在。”
